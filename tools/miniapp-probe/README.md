# Изолированная проба VK Mini App — этап 0

Это **не** рабочее приложение «Найти лекцию по Экобезу». Проба проверяет только Bridge, HTTPS-вход и серверную подпись. Не подключает bot, поиск, AI, БД, VK API или сообщения. Не входит в production-образ.

App ID для пробы: `54916430`. Тестовое сообщество: `https://vk.ru/asukp`, ID `227623179` (публичные `utils.resolveScreenName`/`groups.getById` на странице, 2026-11-23). Название выбрано владельцем: «Найти лекцию по Экобезу».

## Что проверяется

- официальный пример HMAC-SHA256/Base64url и изменение параметра;
- `vk_app_id`, положительный `vk_user_id`, `vk_ts` и все текущие `vk_*`, включая пустые;
- Bridge `VKWebAppInit`, исходная `window.location.search`, перезагрузка/новый вход;
- iframe и переходы по стабильным HTTPS-ссылкам на телефоне/ПК.

Секрет читает только `server.py`. Access log выключен; query, тело, `sign`, токены и заголовки не выводятся. Страница не сохраняет launch query и не передаёт её третьим сторонам. Значения секретов не записывать в `package.json`, `dist`, отчёты или чат.

## Установка

Выполнено для Node 24.14.1 / npm 11.11.0; зависимости зафиксированы `package-lock.json`.

```powershell
npm --prefix tools/miniapp-probe ci
npm --prefix tools/miniapp-probe test
npm --prefix tools/miniapp-probe run build
py -3.12 -m venv tools/miniapp-probe/.venv
tools/miniapp-probe/.venv/Scripts/python.exe -m pip install --require-hashes -r tools/miniapp-probe/requirements.txt
```

Если `py` недоступен, использовать установленный Python 3.12, не менеджер пакетов проекта. Виртуальная среда и `.env` игнорируются Git.

## Локальные настройки

Скопировать `.env.example` в `.env` и заполнить только локально:

- `MINIAPP_APP_SECRET` — из админки приложения: **Разработка → Ключи доступа → Защищённый ключ**;
- `MINIAPP_PUBLIC_ORIGIN` — точный HTTPS-origin Quick Tunnel без пути и `/` в конце.

Не добавлять секрет в `VITE_*`: Vite встраивает такие значения в браузерную сборку.

## HTTPS и запуск

Установлен `cloudflared` 2026.11.1 через winget с проверкой хеша установщика.

1. Собрать frontend и запустить `tools/miniapp-probe/run.ps1` на `127.0.0.1:8787`.
2. В отдельном терминале:

   ```powershell
   cloudflared tunnel --url http://127.0.0.1:8787 --no-autoupdate
   ```

3. Взять выданный `https://*.trycloudflare.com`, указать его в `.env` и в админке Mini App как адрес приложения для Web/мобильных платформ. Перезапустить сервер после изменения origin. Не открывать порт Python наружу.
4. Установить/обновить запуск приложения в тестовом сообществе. Открыть из плитки в VK, не просто в браузере.
5. Проверить: успешный статус; изменение подписанного значения отклоняется; повторная загрузка/новый вход; открытие контрольных ссылок; iframe. Результаты записывать в `specs/004-vk-mini-app/research.md` без query и секретов.

Quick Tunnel публичен для всех, кто знает адрес; здесь нет доступа к каталогу или рабочим сервисам. После пробы остановить оба процесса `Ctrl+C`. При смене адреса обновить и админку, и `.env`.

Все `vk_*` сортируются; `sign` не входит в HMAC. Проверка использует `hmac.compare_digest`, app/user/ts — после проверки формата и HMAC. Возраст `300/+60` секунд и размер query — политика проекта, не норматив VK.

Официальные PHP/Python-примеры кодируют пробел как `+`, JavaScript — как `%20`; текст документации приводит `%20`. Проба принимает лишь одно из этих двух **точных** канонических представлений, если оно даёт ожидаемый HMAC. Это не произвольный выбор варианта и не обход подписи; наблюдаемый реальный формат зафиксировать в T003. Все пустые `vk_*` сохраняются; дубли и неверная кодировка отклоняются.
