# Контракт команд оператора

Команды запускаются через `docker compose run --rm indexer python -m ecoprofi.indexer …`. Команды 002 (`--schedule-file`, `--schedule-url`, `--materials`, `--report`, `--control-posts`) сохраняются; `--materials` и `--control-posts` берут доступ из хранилища, скрытого приглашения токена больше нет.

Ни одна команда не печатает значения доступа, код входа и адреса файлов.

## Доступ

| Команда | Действие | Результат и код выхода |
| --- | --- | --- |
| `access login` | Печатает адрес входа VK ID. Оператор входит в браузере и вставляет адрес возврата в скрытое приглашение. Команда обменивает код, сохраняет доступ, проверяет чтение платной ленты | «Доступ сохранён, платная лента читается». 0 — успех; 2 — вход не состоялся (прежнее состояние не меняется) |
| `access check` | Продлевает доступ, если срок близок, и делает один вызов чтения ленты | Состояние, время последнего продления, срок рабочего токена. 0 — действует; 3 — нужен вход |
| `access forget` | Удаляет сохранённые значения доступа | Состояние `absent`. 0 |

Номер приложения VK ID задаётся переменной `VK_ID_APP` сервисов индексатора; адрес возврата — `https://localhost/callback`.

## Проходы

| Команда | Действие | Результат и код выхода |
| --- | --- | --- |
| `run full [--portion N]` | Начать полный проход либо продолжить незавершённый. Работает в переднем плане; прерывание безопасно | По каждой порции: номер, число лекций, итоги материалов; в конце — сводка по итоговым состояниям. 0 — проход завершён; 1 — завершён, есть отложенные или сбойные материалы; 3 — остановлен, нужен вход или платная лента не читается доступом оператора; 4 — остановлен по лимиту; 5 — идёт другой проход |
| `run update` | Внеочередное плановое обновление (или продолжение незавершённого прохода) | Как выше |
| `run cancel` | Отменить незавершённый проход: следующий запуск начнёт новый список | Номер отменённого прохода. 0 |
| `requeue <ключ материала>` | Вернуть материал из постоянного сбоя в очередь | 0; 2 — материал не найден или не в постоянном сбое |

## Расписание запусков

| Команда | Действие | Результат и код выхода |
| --- | --- | --- |
| `schedule show` | Показать время, признак включения, последний и следующий срок | 0 |
| `schedule set ЧЧ:ММ [ЧЧ:ММ]` | Назначить утреннее и вечернее время по Москве; одно значение — один запуск в сутки. По умолчанию 07:00 и 19:00 | 0; 2 — отказ: больше двух значений либо между ними меньше шести часов |
| `schedule on` | Включить автоматические запуски | 0; 2 — отказ: не наблюдались успешное продление и вход после состояния «нужен вход» (FR-14), с указанием недостающего |
| `schedule off` | Приостановить | 0 |

Сервис `indexer-daemon` команд не принимает: он читает расписание запусков из БД.

## Сводка

`status` печатает и возвращает 0:

- доступ: состояние, время последнего продления, сколько осталось рабочему токену;
- текущий или последний проход: вид, состояние, время начала, пройдено и осталось лекций, номер порции;
- последний успешный проход и возраст индекса;
- материалы по итоговым состояниям ([модель данных](../data-model.md));
- очередь: отложенные с ближайшим сроком, постоянные сбои (ключи), публикации, пропавшие из ленты;
- оповещения: открытые и недоставленные, с временем открытия;
- расписание запусков: время, включено ли, следующий срок.

## Настройки

| Переменная | Сервис | Значение по умолчанию |
| --- | --- | --- |
| `VK_ID_APP` | indexer, indexer-daemon | — (обязательна) |
| `SCHEDULE_URL` | indexer, indexer-daemon | адрес расписания лекций |
| `RUN_PORTION` | indexer, indexer-daemon | 5 лекций |
| `PERMANENT_AFTER_RUNS` | indexer, indexer-daemon | 3 прохода |
| `PAID_FEED_MIN_RATIO` | indexer, indexer-daemon | 0.5 — доля объёма платной ленты последнего успешного прохода |
| `ALERT_STALE_HOURS` | bot | 48 |
| `ALERT_VK_USER_ID` | vk-adapter | — (без неё оповещения копятся и видны в сводке) |
