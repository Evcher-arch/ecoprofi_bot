# Приёмка 006: распознавание записей без субтитров

Протокол по принципу V. Для каждой пробы записываются: дата, среда, способ авторизации, материал, наблюдаемый результат, открытый вопрос. Ключи, временные адреса VK и значения доступа сюда не вносятся. Сценарии — [quickstart.md](quickstart.md).

**Статус:** код готов, автотесты без БД пройдены (31). Тесты с БД, развёртывание и пробы ещё не выполнены: их выполняет агент на ПК с распознавателем по [handoff-asr-pc.md](handoff-asr-pc.md).
