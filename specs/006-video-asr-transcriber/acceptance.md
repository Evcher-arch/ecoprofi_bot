# Приёмка 006: распознавание записей без субтитров

Протокол по принципу V. Для каждой пробы записываются: дата, среда, способ авторизации, материал, наблюдаемый результат, открытый вопрос. Ключи, временные адреса VK и значения доступа сюда не вносятся. Сценарии — [quickstart.md](quickstart.md).

**Итог от 2026-11-28 — приёмка остановлена, спецификация закрыта по решению владельца.** Работающий шлюз на VPS выдал задание воркеру на ПК с RTX 4070. Для контрольной записи VK не предоставил источник, который умеет обрабатывать реализация 006.

### Результат живой пробы

| Проверка | Наблюдение 2026-11-28 |
| --- | --- |
| Материал и запуск | `run-now --only=-95098598_456239778` при включённой паузе. Категория доступа записи отдельно не подтверждена. |
| Связь | Воркер прошёл авторизацию, получил задание и повторно брал его после ошибки получения звука. |
| Причина | На VPS команда `jobs`, журнал шлюза и отдельная проба `probe` показали `audio_unavailable (no_file)`. В ответе `video.get` поле `files` отсутствовало. `direct_url` и `share_url` вели на страницу видео, `player` — на страницу плеера. |
| Граница проверки | На этой записи до извлечения звука и запуска Whisper дело не дошло. Расшифровка, публикация и поиск по речи не подтверждены. Вторую контрольную запись не проверяли. |

Решение относится к способу получения звука в 006. Возможность работы с другими записями или источниками звука по этой пробе не оценивалась. Пустые поля ниже означают отсутствие замера.
