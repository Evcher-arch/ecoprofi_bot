# Контракт: команды оператора для распознавания

Команды запускаются на VPS:

```bash
docker compose -f compose.yaml -f compose.vps.yaml --profile indexer run --rm indexer python -m ecoprofi.asr <команда>
```

Формат вывода такой же, как у команд индексатора из [003](../003-autonomous-indexer/contracts/operator-commands.md): человекочитаемый текст, а с флагом `--json` — JSON. Ни одна команда не печатает ключи, кроме однократного вывода `worker add`.

| Команда | Назначение | Требование |
| --- | --- | --- |
| `worker add <имя>` | Выпустить ключ распознавателя. Ключ печатается один раз, в БД хранится хеш | FR-03 |
| `worker revoke <имя>` | Отозвать ключ: следующие запросы получают `401`, действующие аренды возвращаются в очередь | FR-03 |
| `worker list` | Имена, время выпуска и отзыва, последняя связь, GPU | FR-16 |
| `schedule show` | График распознавания и график индексатора рядом. Это наглядно показывает, что они независимы | FR-10 |
| `schedule set --days 7 --at 01:00 --window 8h [--catch-up on\|off]` | Изменить график распознавания. График индексатора не меняется | FR-10 |
| `pause` / `resume` | Приостановить или возобновить автоматические запуски, включая первичный проход | FR-12, FR-19 |
| `run-now [--only <owner>_<item>[,…]]` | Внеочередной запуск при следующем выходе ПК на связь. Не действует, если запуск уже идёт. С `--only` распознаются только указанные записи, и запуск проходит даже при паузе, не открывая первичный проход (для пробы, quickstart §2) | FR-12, история 1 |
| `status` | Сводка: задания по исходам, первичный проход (сделано / всего), последний запуск и его исход, последняя связь ПК, часы звука, время обработки, скорость (ч записи / ч работы) | FR-16, SC-09 |
| `jobs [--state <состояние>]` | Список заданий с причинами. Без временных адресов | FR-14 |
| `requeue <owner>_<item>` | Вернуть запись в очередь, сбросить `failed_runs` и закрыть оповещение `asr_permanent` | FR-18 |
| `reprocess --processor-version <версия>` | Поставить в очередь записи, распознанные другой версией распознавателя | FR-18 |
| `probe <owner>_<item>` | Проба истории 1: подготовить звук на сервере и показать, какие поля медиа вернул `video.get`, размер, длительность и время подготовки. Звук не сохраняется дольше пробы | История 1, R1 |
