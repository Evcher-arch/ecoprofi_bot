# Контракт ответа поиска: карточки материалов

Расширяет [контракт личного диалога 001](../../001-find-lecture-episode/contracts/local-dialog.md). Вход, проверки группы и участника, доставка, повтор события и коды 401/403/422 не меняются.

## POST /api/search — ответ 200

Поля `event_id`, `peer_id`, `outcome`, `text`, `cards` сохраняются. Изменения только добавляют поля, поэтому адаптер 001 продолжает работать: он отправляет `text`.

`outcome` — `found`, `clarify` или `empty`. `cards` — до трёх карточек; не более двух от одной лекции, если подтверждены материалы других лекций.

### Общие поля карточки

| Поле | Содержание |
| --- | --- |
| `type` | `episode`, `page`, `letter`, `material` или `navigation` |
| `material_id` | Идентификатор материала |
| `title` | Название материала из каталога |
| `lecture` | `{ "title", "date" }` — лекция расписания; дата в виде `ГГГГ-ММ-ДД` |
| `explanation` | Основание выбора. Модель видит только разрешённые выдержки текущего поиска |
| `url` | Стабильная ссылка без ключей доступа |

### Поля по виду карточки

| `type` | Дополнительные поля | Когда выдаётся |
| --- | --- | --- |
| `episode` | `excerpt`, `start_ms`, `end_ms` | Как в 001. `url` содержит позицию начала |
| `page` | `excerpt`, `page`, `pages_total`, `recognized` | Текст этой страницы подтверждает вопрос. `recognized: true` — текст получен распознаванием |
| `letter` | `excerpt`, `requisites` — `{ "date", "number", "sender" }` либо `null`, `requisites_note` | Часть письма подтверждает вопрос. `requisites` заполнены только при состоянии `confirmed`; иначе `null` и пометка «реквизиты не подтверждены» |
| `material` | — | Материал подтверждён названием или реквизитами, но места в тексте нет (нечитаемые страницы, неподдерживаемый формат). Без страницы, реквизитов и выдержки |
| `navigation` | — | Как в 001: запись без пригодной дорожки |

Сервер берёт `excerpt`, `page`, `requisites`, `title`, `lecture` и `url` из каталога одной опубликованной версии. Модель не может их изменить и не может добавить кандидата вне текущего поиска.

### Ссылка

- `episode`, `navigation` — адрес записи, для эпизода с позицией начала в секундах (округление вниз).
- `page`, `letter`, `material` — адрес публикации, к которой приложен документ. Прямой адрес документа допускается только после пробы R7 ([research.md](../research.md)). Адрес файла из вложения участнику не передаётся и не сохраняется.

### Исходы

| Исход | Условие | Содержание |
| --- | --- | --- |
| `found` | Есть подтверждённые кандидаты, лидер определён | До трёх карточек |
| `clarify` | Совпадение слабое, либо оценки материалов разных лекций близки | Один вопрос: какая лекция или какой вид материала нужен. Карточек нет |
| `empty` | Подтверждения нет | Сообщение об отсутствии материала. Страниц, реквизитов и таймкодов нет |

### Права

Аудитория участника определяется до обоих видов поиска и перепроверяется перед возвратом и перед повторной доставкой. При ограниченной роли закрытый материал отсутствует во всех исходах: в карточках, выдержках, реквизитах, тексте уточнения и данных, переданных модели. Материал с неподтверждённой аудиторией не выдаётся ни одной роли.

## Текст сообщения

`text` формируется сервером из карточек. Для каждой карточки — строка с лекцией и датой, вид и название материала, место в источнике, выдержка, ссылка.

```text
Лекция 4. Негативное воздействие на окружающую среду · 27.08.2025
Презентация, стр. 2 из 8
«…плата за негативное воздействие взимается за выбросы, сбросы и размещение отходов…»
https://vk.com/wall-95098598_41120
```

```text
Разбор перечня 2909-р · 27.08.2025
Письмо от 08.02.2024 № ВЧ-09-03-34/3616
«…»
https://vk.com/wall-95098598_30861
```

Выдержки в примерах условные; реквизиты и номера публикаций — контрольные ориентиры спецификации.
