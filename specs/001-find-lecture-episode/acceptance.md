## 4. Открытые вопросы

- **Формат API AI Studio.** Закрыт: векторизация через `foundationModels/v1/textEmbedding` и пояснение через `v1/chat/completions` с заголовком `Api-Key` работают с реальным ключом (T015).
- **Идентификаторы видео для политики.** Аудитория задаётся парой owner_id/video_id, а владельцу известны номера постов. Пары станут видны после прохода индексатора (T018); до разметки материал в выдачу не попадает.
- **Форма субтитров в ответе VK.** Поле `subtitles` с адресом дорожки взято из диагностического скрипта; на реальном ответе индексатор не запускался (T018).
- **Правило повторов.** Подтвердилось на реальной дорожке: повторяются стыкующиеся реплики без перекрытия по времени. Правило расширено на стык (до 100 мс) и на границу эпизодов; проверено на синтетической «бегущей» дорожке, реальная проверка — при повторном проходе (T018).
- **Контрольный ориентир 26:03–26:30.** Закрыт: относится к записи поста 30861, после её загрузки эпизод найден на 1563-й секунде.
- **Слова из названия записи.** Подтверждение эпизода считает только слова его текста. Запрос «перечень 2909-р» даёт `clarify`: номер документа есть в названии лекции, но в речи эпизодов он звучит иначе. Учитывать ли название при подтверждении — решить при калибровке порога (T027).
- **Порог слабого совпадения.** Эпизод подтверждается долей слов вопроса в тексте (не менее 0,6). Векторная близость влияет только на порядок; её пороги (`SEARCH_SIM_STRONG`, `SEARCH_SIM_WEAK`) выключены до калибровки на реальной модели (T027).
- **Связь с расписанием.** Оба контрольных поста привязаны к одной условной строке `pilot-control`; настоящие строки расписания владелец пока не называл.
